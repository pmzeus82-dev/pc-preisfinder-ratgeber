# PC-Preisfinder – Ratgeber

Fachartikel für die Android-App **PC-Preisfinder** (Rubrik „Ratgeber“).

- Feed: [`articles.json`](articles.json) – wird von der App über
  `https://raw.githubusercontent.com/pmzeus82-dev/pc-preisfinder-ratgeber/main/articles.json` geladen.
- Format: JSON (Version 1), Artikeltext in einfachem Markdown; Details siehe [`DAILY_ARTICLE_HOWTO.md`](DAILY_ARTICLE_HOWTO.md).
- Inhalte sind allgemeine Informationen ohne Gewähr – keine Testergebnisse, keine festen Preise.
  Maßgeblich sind Herstellerangaben und Datenblätter.
